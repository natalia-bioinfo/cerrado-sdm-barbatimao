# cerrado-sdm-barbatimao
Modelagem de nicho ecológico do barbatimão (Stryphnodendron adstringens) no Cerrado
1394 registros do GBIF para Stryphnodendron adstringens no Brasil, com coordenadas;
nomes de estados padronizados;
anos de 2012 a 2026;
estados líderes: SP, DF e MG, o que sugere viés de amostragem.
